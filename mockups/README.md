# Kiamora GUI Mockups

Each mockup is supplied in editable SVG and rendered PNG formats at 1600×1000.

## Storefront

- `storefront-product-colour-selection` — product detail page with Yellow, White and Rose Gold selector. The Rose Gold choice updates the gallery and enquiry state.

## Administrative portal

- `admin-dashboard` — catalogue metrics, content-health checks, recent products and quick actions.
- `admin-product-colour-images` — colour variants, multiple images per colour, primary image, alt-text readiness and publication controls.
- `admin-users` — multiple administrator accounts, roles, statuses, invitation flow and last-sign-in visibility.

Use `UI_SPECS.md` for interaction, accessibility, responsive and Angular component requirements. Mockup content is illustrative and must not be treated as approved production data.
